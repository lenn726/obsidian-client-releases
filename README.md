# obsidian-client-releases
   Erste Beta von Obsidian Client.

   Installation: Obsidian-Client-Setup-0.9.0-beta.exe herunterladen und starten.
   Hinweis: Der Installer ist noch nicht code-signiert. Windows SmartScreen kann deshalb warnen. Klicke dann auf "Weitere Informationen" und "Trotzdem ausführen".

   Neu: Update-Knopf (Einstellungen → Updates), Server-Hub, Bedrock-Port-Korrektur.
   Die Dateien latest.json und latest.json.sig brauchst du nicht, die sind für die automatische Update-Prüfung.
